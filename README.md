# Русификатор для Heirs of Dust

Русская локализация мода **Heirs of Dust** для Mount & Blade: Warband.

## Установка

Скопировать папки `languages` и `Data`, `Textures` в `Modules\Kenshi\`. Согласится на замену.


## Состав

- `languages/ru/` — файлы локализации
- `Data/FONT_DATA.XML` и `Textures/FONT.DDS` — шрифт с поддержкой кириллицы
